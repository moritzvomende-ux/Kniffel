KNIFFEL CLUB – GitHub Pages

1. Öffne github.com und melde dich an.
2. Erstelle ein neues öffentliches Repository, z. B. „kniffel“.
3. Wähle im Repository „Add file“ → „Upload files“.
4. Lade die Datei index.html aus diesem Ordner hoch (wichtig: genau dieser Dateiname).
5. Klicke „Commit changes“.
6. Unter „Settings“ → „Pages“ wähle „Deploy from a branch“, Branch „main“ und „/(root)“ und speichere.
7. Die Website ist anschließend unter https://DEIN-NUTZERNAME.github.io/kniffel/ erreichbar.

Hinweise:
- Kein Server nötig. Jeder Browser speichert seinen eigenen Spielstand lokal.
- Die Funktion „Gemeinsam“ verwaltet mehrere Spieler auf einem einzigen Gerät.
- Es gibt digitale Würfel (Würfeln, Festhalten, Wischen) und einen Modus für echte Würfel.
- Die Standardwertung umfasst 13 Kategorien und den oberen Bonus ab 63 Punkten.
- Sonderregeln für zusätzliche Kniffel und Joker sind in dieser ersten Version nicht enthalten.
- Offline-Nutzung ist nicht garantiert; die Seite muss erreichbar sein, um geöffnet zu werden.
